# A Developer's Reflection: 6 Months of Better Dogs

**Date:** June 29, 2026

I just had a sudden realization today—I have been working on **Better Dogs** for over 6 months! 

this file is public

So, here is what I have found over these 6 months:
1. People really don't care about supporting Minecraft modding; it's free, so it's free, unless you make something like paid cosmetics.
2. Even though I tried to make it so only power users could get the latest features of the mods, the ceiling is lower now because of AI. Anyone can download the code and ask an AI to compile it, and it will try multiple times until it works.
3. So, even if I made it with AI assistance, it doesn't really matter. It's more about how much you care about it; this doesn't feel like slop at all.
4. Because I placed limitations on myself—like using vanilla assets first with no custom assets so it's mostly code-only—it made the process more interesting. Making stuff that feels like it actually matters to me gives features real meaning, rather than just doing it for the sake of "because I can."
5. I should have made this as a datapack rather than a mod. Because it's so simple, it could have been created using datapacks instead of mods, which might have made it more popular. However, I think I should finish it first before trying to port it to datapacks.
6. I tried using NeoForge, but I don't think I am smart enough to use it; I still prefer using Fabric.
7. Using AI feels like this: instead of walking a kilometers-long road, I can just take a taxi to get to where I want.
